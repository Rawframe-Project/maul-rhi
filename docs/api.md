# Maul RHI API reference

Generated from the public headers by `tools/gen_api.py`. The headers
are the source of truth; this file mirrors them.

## `base.h`

The base of the Maul RHI API: the library and contract versions, the export and attribute macros, the result codes every fallible function returns, the allocator and the extension chain. Generated by tools/gen_contract.py from docs/contract/mrhi.json: edit the contract, not this file.

```c
mrhiVersion mrhiGetVersion(void);
```
Returns the version of the library that was linked, which may differ from the MRHI_VERSION macros a program was compiled with.  @return The library version. @par Thread safety Safe from any thread.

```c
const char* mrhiResultName(mrhiResult result);
```
Returns the name of a result code, for diagnostics.  @param result  Any value; an unknown one is named as such. @return A static, NUL-terminated string such as "mrhi_errorCapacity". @par Thread safety Safe from any thread.

```c
const char* mrhiDiagnosticText(mrhiDiagnosticCode code);
```
Returns the text of a diagnostic code, for people; programs compare codes, never texts.  @param code  Any value; an unknown one has a text saying so. @return A static, NUL-terminated English sentence. @par Thread safety Safe from any thread.

## `d3d12.h`

D3D12 objects for vendor upscalers (mrhi-0019): the device's native objects, a texture's resource, and the command list a native pass runs. Every other driver answers the functions unsupported. Generated by tools/gen_contract.py from docs/contract/mrhi.json: edit the contract, not this file.

```c
MRHI_NODISCARD MRHI_API mrhiResult mrhiGetD3d12Device(mrhiDevice* device, void** deviceOut, void** queueOut);
```
Reads a D3D12 device's native objects, borrowed for the device's life with no reference added: what an upscaler's context is made from (the FidelityFX SDK's backend, XeSS's xessD3D12CreateContext).  @param device     The device. @param deviceOut  Receives the ID3D12Device*. @param queueOut   Receives the ID3D12CommandQueue* the device submits on. @return `mrhi_success`; `mrhi_errorUnsupported` where the device's driver is not D3D12; `mrhi_errorInvalid` for a NULL argument. @par Thread safety Safe from any thread; the device is used by one thread at a time.

```c
MRHI_NODISCARD MRHI_API mrhiResult mrhiGetD3d12Texture(mrhiDevice* device, mrhiTextureId texture, void** resourceOut);
```
Reads a device texture's ID3D12Resource, borrowed with no reference added. In a native pass the texture is in the state its access puts it in: D3D12_RESOURCE_STATE_PIXEL_SHADER_RESOURCE | D3D12_RESOURCE_STATE_NON_PIXEL_SHADER_RESOURCE for mrhi_accessSampled, D3D12_RESOURCE_STATE_UNORDERED_ACCESS for the storage accesses, D3D12_RESOURCE_STATE_COPY_SOURCE and D3D12_RESOURCE_STATE_COPY_DEST for the copies; a buffer is in D3D12_RESOURCE_STATE_COMMON, promoted on its first use, as buffers decay between command lists.  @param device       The device. @param texture      The texture. @param resourceOut  Receives the ID3D12Resource*. @return `mrhi_success`; `mrhi_errorUnsupported` where the device's driver is not D3D12; `mrhi_errorStale` for a texture the device no longer has; `mrhi_errorInvalid` for a NULL argument. @par Thread safety Safe from any thread; the device is used by one thread at a time.

```c
MRHI_NODISCARD MRHI_API mrhiResult mrhiSetD3d12PassCommands(mrhiDevice* device, mrhiPassId pass, void* commandList);
```
Hands a native pass the command list the program recorded for it: an ID3D12GraphicsCommandList of the direct type, closed and not executed. The library executes it at the pass's place in the frame, after the library's lists before it and before those after it, each in its own ExecuteCommandLists; it must leave every declared texture in its access's state (mrhiGetD3d12Texture), and may change any other state, its descriptor heaps and root signatures included. The program keeps it alive until the frame is done.  @param device       The device. @param pass         The native pass, begun. @param commandList  The ID3D12GraphicsCommandList*. @return `mrhi_success`; `mrhi_errorUnsupported` where the device's driver is not D3D12; `mrhi_errorState` outside the pass's recording, or for a pass that already has one; `mrhi_errorInvalid` for a NULL list or a pass that is not native. @par Thread safety Safe from any thread; the device is used by one thread at a time.

## `device.h`


## `encoder.h`

Recording: a kept pass of a compiled frame is begun, its commands recorded, and ended, all before the frame is submitted. The pass id is the encoder. Different passes may record on different threads at once; while passes record, nothing else uses the device. Generated by tools/gen_contract.py from docs/contract/mrhi.json: edit the contract, not this file.

```c
MRHI_NODISCARD MRHI_API mrhiResult mrhiBeginPass(mrhiDevice* device, mrhiPassId pass);
```
Begins recording a kept pass of the compiled open frame. It records until mrhiEndPass; a kept pass never begun records nothing.  @param device  The device. @param pass    The pass. @return `mrhi_success`; `mrhi_errorInvalid` for a NULL device; `mrhi_errorStale` for a pass of another frame or none; `mrhi_errorState` for a pass that is culled, begun already, or a frame that is not compiled. @par Thread safety Safe from any thread; the pass is used by one thread at a time.

```c
MRHI_NODISCARD MRHI_API mrhiResult mrhiEndPass(mrhiDevice* device, mrhiPassId pass);
```
Ends recording a pass. Its debug groups must be closed.  @param device  The device. @param pass    The pass, recording. @return `mrhi_success`; `mrhi_errorInvalid` for a NULL device, open debug groups, or an open occlusion or statistics query; `mrhi_errorStale` for a pass of another frame or none; `mrhi_errorState` for a pass that is not recording. @par Thread safety Safe from any thread; the pass is used by one thread at a time.

## `frame.h`

Frames: the frame graph, the only way work reaches the GPU. A frame is begun, its resources and passes declared, compiled, recorded and submitted; submitting returns a token that the device's notification queue answers once the GPU has finished. Generated by tools/gen_contract.py from docs/contract/mrhi.json: edit the contract, not this file.
